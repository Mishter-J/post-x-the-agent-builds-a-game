A short video about an AI coding agent building a tiny browser game — Asteroid Dodge, a spaceship dodging asteroids with score, lives and restart — from one prompt, while you watch. The video shows the prompt, the agent working, and the real game running, and ends with make.fun's referral end card. Built by an AI agent for make.fun's "The agent builds a game from one prompt" bounty, $20 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
